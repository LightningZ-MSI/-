术语
规划功耗
把所有硬件「最多能吃多少电」加在一起。电源必须扛得住这个数。
场景预期功耗
你实际用起来大概会吃多少电。这个数通常比规划功耗小， 因为打游戏时 CPU 一般不会同时跑满。
瞬时峰值
显卡在极短一瞬间能拉到的最高功率（比平均值高很多）。 这是为什么不能用杂牌电源的原因——它们的标称瓦数扛不住这种瞬间冲击。
TDP / 最大睿频功耗
CPU 的耗电指标。一个是「平时」，一个是「火力全开」。 本工具按火力全开算，更保险。
AIC 厂商 / 板型
同样一颗显卡芯片，华硕、微星、技嘉等厂商会做成不同版本， 耗电和尺寸都不一样。比如「微星闪电」就比公版耗电高得多。
12V-2x6 / 12VHPWR
RTX 40/50 系显卡用的新供电接口。买电源时要确认它自带这个接口， 否则得用转接线（有风险）。
ATX 3.1
最新一代电源规范，专门为「瞬时峰值」做了加强。 配 RTX 50 系 / RX 9000 系显卡建议选它。
80 PLUS 金牌 / 铂金 / 钛金
电源的省电效率等级。等级越高越省电、发热越小，但也越贵。 预算有限时优先保瓦数，再考虑等级。

功耗数值都是估算值

本工具的所有功耗数值来自厂商规格页、权威评测与公开泄露信息，每一条都标注了 official review estimate leak 置信度与来源。电源选型的本质是估算，真实功耗取决于具体软件负载、BIOS 功耗墙 设置与环境温度。本结果适合用来排除「明显不够用」的电源，不应替代厂商官方建议。 标为 leak 的硬件尚未发布，仅可用于前瞻推演。

「显卡适配主板」是什么意思

同一颗 GPU 由不同 AIC 厂商做成不同的板型 / PCB（如 ROG Astral、SUPRIM、 AORUS MASTER），功耗墙与供电接口各不相同，所以第 3 步选的是显卡板型。 至于系统主板（如 Z890 / B850）与 CPU 的插槽兼容性，在第 4 步校验。

纯血老卡与二手硬件的提醒

数据库同时收录了 GTX 900 / 10 系、RTX 20 / 30 系与 RX 500 / 5000 / 6000 系等 已停产的显卡，方便沿用旧机时估算。这些型号的厂商功耗墙多为规则推算而非 官方数据，且旧卡经过多年使用后电容老化、硅脂干涸会让实际功耗与峰值抖动变大， 建议比计算结果再留一档余量。已停产的硬件在市面上只能买到二手，请自行判断成色与保修。
